    Вас беспокоит Что происходит на самом деле Почему это так
    «Он что-нибудь отправит от моего имени». Сразу после подключения он только читает. Писать он сможет, только если вы разрешите это при входе, и только в чаты, в которые разрешено отправлять (их вы выбираете сами), не больше установленного лимита. Спрашивать ли вас перед каждой отправкой, решает ваше ИИ-приложение. Или разрешите только черновики — их вы отправите сами. Разрешения вы выбираете на экране входа. Инструменты, которые вы не разрешили, ИИ даже не видит, а чаты и лимиты сервер проверяет сам, что бы ни просил ИИ.
    «Разработчик будет читать мои чаты». Ваши сообщения нигде не хранятся. Ваш сеанс Telegram зашифрован ключом, которого у разработчика нет. Ключ есть только в токенах входа, которые хранит ваше ИИ-приложение. Сервер хранит сеанс зашифрованным и сам открыть его не может.
    «У меня украдут пароль или аккаунт». Пароль вы вводите на странице входа самого tg-mcp, и ИИ его не видит. В украденной базе данных нет ничего, что можно прочитать. Вход по QR-коду и ввод облачного пароля происходят вне ИИ-приложения. Сеанс в базе данных зашифрован.
    «Я не смогу его отключить». Одно касание: Telegram → Настройки → Устройства → завершите сеанс «Unofficial MCP Server». Сервер по-настоящему выходит из аккаунта. При следующем запросе ваш ИИ получит ошибку.

    Вопросы.

    Что такое MCP-сервер для Telegram?

    MCP (Model Context Protocol) — открытый стандарт, через который ИИ-приложения подключают внешние инструменты. tg-mcp — MCP-сервер для вашего личного аккаунта Telegram: после подключения ИИ может просматривать список чатов, читать и искать сообщения, смотреть фото, расшифровывать голосовые сообщения и, только если вы разрешите, писать черновики или отправлять сообщения в чаты, в которые разрешено отправлять.

    Как подключить Телеграм к Claude, ChatGPT или Gemini?

    Добавьте https://connector.tgmcp.dev/mcp как свой коннектор. В Claude: Настройки → Коннекторы → Добавить свой коннектор (Settings → Connectors → Add custom connector). В ChatGPT (платные тарифы): Настройки → Приложения и коннекторы → Дополнительно → Режим разработчика, затем «Создать» (Settings → Apps & Connectors → Advanced → Developer mode, Create). В Gemini: Настройки → Подключённые приложения → Добавить своё приложение (Settings → Connected apps → Add a custom app). Затем отсканируйте QR-код в Telegram на телефоне. В Claude Code: claude mcp add --transport http telegram https://connector.tgmcp.dev/mcp. Cursor и другие MCP-клиенты принимают тот же адрес как streamable-HTTP-сервер.

    Это бесплатно? Нужен API-ключ или бот?

    Бесплатно: без регистрации, без оплаты и без API-ключа. Сервер входит в ваш собственный аккаунт по QR-коду, как Telegram Desktop, и работает с вашими настоящими чатами, а не с чатами бота.

    Чем он отличается от других MCP-серверов для Telegram?

    Большинство MCP-серверов для Telegram работают на вашем компьютере: нужно поставить Python или Node, получить API id и hash на my.telegram.org и хранить файл сеанса на диске. tg-mcp — удалённый сервер, который добавляется по ссылке, поэтому он работает в Claude, ChatGPT и Gemini — и в браузере, и на телефоне. Ваш сеанс Telegram хранится в зашифрованном виде, а ключ есть только у вашего ИИ-приложения; собственную копию по-прежнему можно запустить в Docker.

    Может ли Telegram заблокировать за это мой аккаунт?

    Сервер работает через официальный API Telegram от имени своего зарегистрированного приложения, держится в пределах лимитов Telegram, а когда Telegram просит подождать, ждёт, а не обходит ограничение повторными запросами. Говорить за Telegram мы не можем, поэтому честно пообещать, что ничего никогда не случится, не может никто.

    Что видит мой ИИ-провайдер?

    Сообщения, которые ИИ читает, чтобы ответить на ваш вопрос, — так же, как если бы вы сами вставили их в чат.

    Я удалил его из ИИ-приложения. Он отключён?

    Не всегда. Некоторые приложения лишь забывают свои ключи, а сеанс Telegram остаётся. Для надёжности завершите его в Telegram → Настройки → Устройства → Unofficial MCP Server.
