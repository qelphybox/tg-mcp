Telegram MCP server · open source

Tell your AI what to do in Telegram.

tg-mcp is a free, open-source remote MCP server for your personal Telegram account. Add one link to Claude, ChatGPT or Gemini, scan a QR code, and your AI can read, search and sum up your chats; it writes only where you allow it.

    You stay in control.

    Not “it's safe”, but exactly what tg-mcp can't do with your account.

    You worry What actually happens Why that's true
    “It will send something as me.” Out of the box it only reads. Writing stays off until you allow it when you sign in, only for the chats you pick, and every message waits for your OK, or becomes a draft you send yourself. You choose permissions on the sign-in screen. Tools you didn't allow aren't even visible to the AI.
    “The developer will read my chats.” Your messages aren't stored anywhere. Your Telegram session is locked with a key the developer doesn't have. The key lives only in the sign-in tokens your AI app holds. The server keeps the session encrypted and can't open it on its own.
    “Someone will steal my password or my account.” You type your password on tg-mcp's own sign-in page, and the AI never sees it. A stolen database has nothing readable in it. The QR login and the cloud password happen outside the AI app. The session in the database is encrypted.
    “I won't be able to turn it off.” One tap: Telegram → Settings → Devices → end the “Unofficial MCP Server” session. That logs the server out for real. Your AI gets an error on its next request.

    Don't trust. Verify.

    Encryption protects what's stored. While your AI reads a chat, the messages pass through the server's memory, so whoever runs the server could, in theory, see them. And whatever you ask goes to your AI provider: OpenAI, Anthropic or Google.

    Questions.

    What is a Telegram MCP server?

    MCP, the Model Context Protocol, is the open standard AI apps use to plug in outside tools. tg-mcp is an MCP server for your personal Telegram account: once it is connected, your AI can list your chats, read and search messages, look at photos, transcribe voice messages and, only if you allow it, write drafts or send messages to the chats you pick.

    How do I connect Telegram to Claude, ChatGPT or Gemini?

    Add https://connector.tgmcp.dev/mcp as a custom connector. In Claude: Settings → Connectors → Add custom connector. In ChatGPT (paid plans): Settings → Apps & Connectors → Advanced → Developer mode, then Create. In Gemini: Settings → Connected apps → Add a custom app. Then scan the QR code with Telegram on your phone. In Claude Code: claude mcp add --transport http telegram https://connector.tgmcp.dev/mcp. Cursor and other MCP clients take the same URL as a streamable-HTTP server.

    Is it free? Do I need an API key or a bot?

    It's free: no sign-up, no payment and no API key. It logs in to your own account with a QR code, like Telegram Desktop does, and works with your real chats, not a bot's. You need your own app id from my.telegram.org only to run your own copy.

    How is it different from other Telegram MCP servers?

    Most Telegram MCP servers run on your own computer: you install Python or Node, get an API id and hash from my.telegram.org, and keep a session file on disk. tg-mcp is a remote server you add by URL, so it also works in Claude, ChatGPT and Gemini on the web and on your phone. Your session is stored encrypted with a key only your AI app holds, and you can still run your own copy with Docker.

    Can Telegram block my account for this?

    It uses Telegram's official API through its own registered app, stays within Telegram's rate limits, and when Telegram asks it to wait, it waits instead of retrying around the limit. We can't speak for Telegram, so nobody can honestly promise that nothing will ever happen.

    Who makes this?

    I do: Kirill Bobykin, an independent developer, @qelphybox on GitHub. tg-mcp is unofficial and not affiliated with Telegram, OpenAI, Anthropic or Google. All the code is public, and issues go straight to me.

    What does my AI provider see?

    The messages the AI reads to answer your question, the same as if you had pasted them into the chat yourself.

    I removed it from my AI app. Is it disconnected?

    Not always. Some apps only forget their keys, and the Telegram session stays. To be sure, end it in Telegram → Settings → Devices → Unofficial MCP Server.
